## Estructura del proyecto

magmasoft/
├── index.html              → Dashboard principal
├── css/
│   └── styles.css          → Estilos globales
├── js/
│   ├── app.js              → Datos y utilidades globales
│   └── components.js       → Topbar, sidebar, bottom nav
└── pages/
    ├── login.html          → Inicio de sesión
    ├── catalogo.html       → Catálogo de productos
    ├── pedidos.html        → Gestión de pedidos
    ├── inventario.html     → Control de inventario
    ├── clientes.html       → Gestión de clientes
    └── notificaciones.html → Centro de notificaciones

## Cómo usar

1. Abrir pages/login.html en cualquier navegador moderno
2. Clic en "Iniciar Sesión" (credenciales ya precargadas)
3. Navegar por el sistema usando el sidebar o los enlaces

## Tecnologías

- HTML5, CSS3 (variables, Flexbox, Grid, responsive), JavaScript ES6+
